# Platform Builder v1.0 — запуск плагина в своём Penpot

Релиз дизайн-системы по ТЗ v1.0. Плагин **идемпотентен**: создаёт всё с нуля,
при повторных запусках пересобирает по именам, ничего не дублируя.

## Состав архива

| Папка | Что это |
|---|---|
| `penpot-plugin/` | **Хостить по HTTPS**: `manifest.json` + `plugin.js` + `icon.svg` |
| `plugin-src/` | Исходники TypeScript (для доработок; сборка — см. ниже) |
| `tokens/` | `design-tokens.json` (DTCG) + `tokens.css` — источник истины |
| `foundations/ uikit/ patterns/` | Спеки итераций 1–3 (HTML, самодостаточные) |
| `screens/` | Спеки итераций 4–10 (HTML, самодостаточные) |
| `docs/` | 01 — установка Penpot · 02 — workflow всех итераций · 03 — чек-листы · **04 — юристу (152-ФЗ)** · **05 — методисту (тексты)** |

## 1. Хостинг манифеста (выберите один путь)

**GitHub Pages (проще всего):**
1. Создайте репозиторий, скопируйте в него содержимое `penpot-plugin/` (три файла в одну папку).
2. Settings → Pages → Deploy from branch → выберите ветку/папку → Save.
3. URL манифеста: `https://<логин>.github.io/<репозиторий>/manifest.json`.

**Свой статический хостинг / сервер Penpot:** положите три файла в одну папку за HTTPS
(Caddy/nginx) и используйте `https://<домен>/penpot/manifest.json`. Путь к `code`/`icon`
в манифесте относительный — файлы должны лежать рядом.

**Быстрая проверка локально (self-hosted Penpot):** `python3 -m http.server 8080`
в папке `penpot-plugin/` → URL `http://localhost:8080/manifest.json`
(localhost Penpot разрешает по http; для облака нужен публичный https).

## 2. Установка в Penpot

1. Откройте свой Penpot → меню (аватар) → **Plugins → Plugin manager**
   (`Ctrl/Cmd + Alt + P`).
2. Вставьте URL манифеста → **Install**. Плагин «Platform Builder» запросит
   разрешения `content:read/write`, `library:read/write` — подтвердите.
3. Создайте/откройте файл проекта и **чистую страницу** (например, «Build»).

## 3. Запуск и что появится

1. Меню → **Plugins → Platform Builder** → Run.
2. На текущей странице появятся **149 бордов** в колонках слева направо:
   `01_Foundations / audit` · `02_Components / UI-kit` (72 компонента) ·
   `03_Patterns / Domain` (34) · экраны **E-01…E-12** · **E-20…E-28** · **E-30…E-44** ·
   **E-50…E-57** (TMA 390, тёмные, safe area 56/80) · **E-60…E-73** (1440/1280) ·
   **E-80…E-85** · `13_Handoff / handoff`.
3. В библиотеку лягут **43 стиля** (33 цвета + 10 текстов) и **106 компонентов** —
   видны в панели Assets.
4. Повторный запуск пересоберёт всё заново (фреймы и потоки сносятся по именам,
   компоненты не дублируются). Полная пересборка занимает ~минуту.

## 4. Проверка потоков в Present

1. Кликните фрейм-источник любого потока и нажмите **Present** (или откройте
   Prototypes/Flows — там 6 потоков: `7.1 Гость…` … `7.6 Админ…`).
2. Проверьте клики: 7.1 E-01→E-02→E-04 · 7.2 E-03→E-10→E-22→E-25 ·
   7.3 E-40→E-41→E-42→E-43 (390) · 7.4 E-50→E-52→E-53→E-54 (390) ·
   7.5 E-68→E-70→E-71 · 7.6 E-60→E-63→E-64.
3. Потоки пересоздаются при каждом запуске плагина (свежие связи после пересборки фреймов).

## 5. Передача фреймов заказчику

- **Вариант А (рекомендуется):** Share → пригласить заказчика в файл/проект,
  затем Share → передать владение (transfer ownership).
- **Вариант Б:** Publish library (стили + компоненты) → заказчик включает библиотеку
  в своих файлах и собирает свои документы из готовых компонентов Assets.
- Фреймы уже названы по паттернам ТЗ (`E-XX Название / брейкпоинт`) — ищутся
  поиском по слою; раскидать по 14 страницам ТЗ можно копипастой бордов.

## 7. Если что-то не так

| Симптом | Причина / фикс |
|---|---|
| Контент сдвинут за границы фреймов вдвое | Поведение координат на живом Penpot (parent-relative) — пишите, дадим фикс одной строки в `draw.ts` (setOrigin) |
| Тексты не Inter | В инстанции нет шрифта — плагин возьмёт fallback; загрузите Inter/JetBrains Mono в организацию |
| Графики-радары/QR упрощённые | Так задумано: SVG-плейсхолдеры; точные графики — в спеках HTML |
| Ошибка при установке по URL | Проверьте, что все три файла лежат в одной папке и манифест открывается в браузере |

## 8. Сборка из исходников (для доработки)

```bash
cd plugin-src
npm install          # @penpot/plugin-types@^1.5.0, typescript, esbuild
npm run typecheck
npm run build        # → dist/plugin.js (заменить в penpot-plugin/ и перезалить хостинг)
```
