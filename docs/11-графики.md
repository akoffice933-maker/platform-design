# 11 · Графики: выбор библиотеки и радар навыков (P1)

Закрывает пункт аудита «SVG-плейсхолдеры (радар/QR/line-chart)». Цепочка
разработки: статичный референс → код на выбранной библиотеке → подключение
в пилот. Плейсхолдеры в макетах остаются референсом композиции, верстать
графики из плагина не нужно.

## 1. Требования к библиотеке

| Критерий | Почему |
|---|---|
| React 18, декларативные компоненты | стек фронта (см. `docs/08`) |
| Кастомные оси/тики/формы | подписи осей радара — 8 навыков, стили из токенов |
| Полярные графики из коробки | радар — основной график продукта |
| Анимации настраиваются до 500ms | `motion/base`, `motion/spring`; бесконечные — запрещены |
| Размер ≤ 60 КБ gzip | библиотека графиков — самая тяжёлая зависимость дашборда |
| SSR не требуется | кабинеты — SPA; TMA — клиентский рендер |

## 2. Сравнение и решение

| Кандидат | + | − | Вердикт |
|---|---|---|---|
| **recharts ^2.12** | декларативность, Radar/PolarGrid из коробки, custom tick, знакомый API | радар без точек «из коробки» (свой `dot`) | **выбрано** |
| visx (@visx) | максимальный контроль, меньше веса | полярные оси собирать самому; дороже в поддержке | резерв, если упрёмся в кастом |
| chart.js + обёртки | лёгкий | императивный, токены протаскиваются костыльно | нет |

## 3. Правила графиков

1. **Цвета — только токены**: линии/заливки `var(--color-accent-primary)`,
   сетки `var(--color-border-default)`, подписи `var(--color-text-secondary)`.
   Дефолтные палитры библиотеки отключать полностью.
2. **Анимации** — длительности из `tokens/motion.css` (400–500ms ease-out);
   никаких бесконечных анимаций, кроме скелетонов E-80.
3. **Тёмная тема TMA** — те же CSS-переменные: recharts читает значения в
   момент рендера, переменные переключаются темой автоматически.
4. **Доступность**: у контейнера `role="img"` + `aria-label` с текстовой
   сводкой («Эмпатия 8 из 10 — выше среднего»); цифры по навыкам дублируются
   списком рядом с графиком в E-25/E-28.
5. **Числа 0–10** — единая шкала для радара и шкал эмоций (не проценты).

## 4. Радар навыков — код

Готовый компонент: [`charts/RadarSkills.jsx`](../charts/RadarSkills.jsx) —
8 осей `skillId` из `docs/09`, полигон «текущая сессия» + пунктир «среднее
за 5». Референс вида: [`charts/radar-skills.svg`](../charts/radar-skills.svg).

```jsx
<RadarSkills
  session={{ listening: 7, empathy: 8, boundaries: 5, /* …все 8 */ }}
  average={{ listening: 6, empathy: 7, /* …все 8 */ }} />
```
