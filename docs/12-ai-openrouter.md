# 12 · ИИ через OpenRouter (фаза 1)

Опциональный ИИ-слой фронтенда: **свободная практика остаётся на детерминированном
контракте docs/09**, ИИ добавляет две функции и никогда не является зависимостью
(нет ключа/сети/лимита — сессия работает полностью, см. «Фолбэк»).

## 1. Что добавлено

| Функция | Где | Суть |
|---|---|---|
| **ИИ-судья** свободных ответов | `input`-узлы сценария | Закрывает пометку docs/09 «скоринг input — на бэкенде»: мини-модель возвращает scores −3…+3 по 8 skillId, kind (strength/growth) и feedback ≤ 90 символов |
| **Варианты реплик клиента** | `text`-узлы | Кнопка «⟳ Вариант реплики от ИИ-клиента»: переформулировка scripted-реплики своими словами. Смысл, эмоция и граф — неизменны |
| Панель настроек | правая колонка сессии | Ключ OpenRouter (BYOK), выбор модели, тумблеры функций; всё в localStorage |

Код: `frontend/src/lib/ai.ts` (API + промпты + валидация + фолбэк), UI — `frontend/src/pages/Session.tsx`.

## 2. Модели (бесплатные)

Дефолт — **`openrouter/free`**: автороутер по бесплатным моделям, переживает
отсутствие отдельных моделей. Селектор (live-список сент. 2026, pricing 0/0):
`google/gemma-4-31b-it:free`, `nvidia/nemotron-3-super-120b-a12b:free`,
`z-ai/glm-5.2:free`, `thinkingmachines/inkling:free`.

Лимиты `:free`-моделей диктует OpenRouter (квоты аккаунта, см. их документацию);
для продакшна — платная мини-модель: доли цента за вызов, зато без дневных лимитов.

**Live-тест ключа (сент. 2026, автороутер `openrouter/free`):** судья → `z-ai/glm-5.2:free`,
валидный JSON, в-границах оценки, ~3 c; реплика клиента → `nex-agi/nex-n2.5-mini:free`,
корректная переформулировка в роли, ~8–22 c. Автороутер выбирает разные модели от вызова
к вызову — часть из них рассуждающая и медленная, встречаются редкие пустые `content`:
обе ситуации закрыты (таймаут 30 c + фолбэк), стоимость тестов $0.

## 3. Контракт ИИ-судьи

**Промпт** (system): «Ты супервизор-психолог… Верни ТОЛЬКО JSON:
`{"scores": {"<skillId>": −3…3}, "kind": "strength"|"growth", "feedback": "…"}»`
+ user: эмоция клиента, подсказки узла, ответ стажёра. Temperature 0.2, ≤ 250 токенов.

**Валидация ответа** (моделям не доверяем):
- извлечение первого `{...}` из ответа, `JSON.parse`;
- skillId — белый список из схемы; значения clamp в −3…+3, нецелые отбрасываются;
- пустой scores / невалидный JSON / ошибка сети → **фолбэк**, сессия не прерывается.

**Фолбэк (детерминированный):** сопоставление ответа с подсказками узла по
3-буквенным префиксам словоформ («самый»~«самое»): ≥ 0.34 → strength с оценками
узла; иначе → growth с ослабленными (sign) оценками. Проверен юнит-тестом на
обоих классах ответов.

## 4. Границы ИИ-клиента

- Переформулируются **только scripted-реплики** узлов `text` — ветвления, эмоции,
  баллы и порядок узлов остаются детерминированными (воспроизводимый разбор);
- **Критический эпизод (`critical`) модели не отдаётся** — импровизация LLM на
  острой реакции недопустима методически;
- Промпт запрещает новые факты и выход из роли; ответ > 220 символов отбрасывается.

## 5. Приватность и 152-ФЗ

- Клиенты симулятора вымышлены — персональных данных клиента нет по умолчанию;
- Свободный текст стажёра уходит в OpenRouter → в панели настроек явный дисклеймер;
  в проде дополнить согласие E-41 пунктом «обработка ответов ИИ-провайдером»;
- Выбирать провайдеров/модели с политикой «не обучаем на данных API»;
- **Ключ в браузере — только демо-BYOK.** Прод: вызовы через серверный прокси
  (Cloudflare Worker / функция бэкенда), ключ на сервере, лимиты и логи на своей стороне.

## 6. Прод-путь (фаза 2+, когда появится бэкенд)

1. Прокси `POST /api/ai/chat` с ключом на сервере; `ai.ts` меняет только `fetch`-строку — интерфейс функций прежний;
2. Тот же валидатор вердикта; лог вердиктов → аналитика качества модели;
3. Кандидаты на следующий этап: автопояснение фидбека, черновики комментариев супервизора, режим «песочница» (свободный диалог вне графа — только как доп. режим).
