## Открытые вопросы (фиксировать по ходу, ТЗ 9.4)

1. Инфо-цвет: для кнопок на `#0EA5E9` белый текст не проходит AA — нужен более
   тёмный `info-strong` (предложение: `#0369A1`) или тёмный текст на кнопках.
2. Warning-кнопки: аналогично — dark-label или `warning-strong` (предложение: `#B45309`).
3. Брендинг/логотип: не входит в дизайн-этап; зарезервировать слот в 00_Cover.
4. Тёмная тема desktop-экранов психолога: ТЗ требует только для TMA/клиентских —
   подтвердить, что web-кабинеты остаются светлыми.
5. «Свой вариант» в сессии (E-22/E-23): beta-флаг в UI — нужен бейдж «beta» в компоненте.
