**Импорт токенов в Penpot (закрывает минус из аудита):**
1. Открыть файл → **Tools → Design Tokens** (правая панель).
2. **Import** → выбрать `tokens/design-tokens.json`.
3. Проверить группы color/typography/space/radius/shadow/motion.
4. Обновлять после правок токенов: export → diff → import (сеты версируются в git).

## 3. Что сознательно НЕ делаем

- Storybook на все 106 компонентов — окупится только при живом фронтенде;
- пиксельный design-to-code экспорт — рабочая связка «спека + пресет + inspect» дешевле;
- доп. брейкпоинты для админки — ТЗ фиксирует 1440/1280 (desktop-first роль).
