# Шаблон текстов для методиста

> В дизайне — макеты с реалистичными заглушками. Чтобы продукт заработал,
> нужны настоящие сценарии и игры. Заполняйте по шаблонам ниже и передавайте
> разработке (или заливайте в CMS). Лимиты символов — из дизайна, менять нельзя
> без правки макетов.

## 1. Сценарий симулятора (экраны E-20…E-28)

| Поле | Лимит | Пример (из дизайна) |
|---|---|---|
| Название | ~48 зн. | «Тревога перед экзаменом» |
| Описание (карточка) | 2 строки | «Клиент-студент за день до экзамена…» |
| Роль клиента | 1 слово | студент / мама / сотрудник |
| Сложность | ★–★★★ | ★★ |
| Фокус-навыки (до 3 из 8) | — | Слушание, Эмпатия |
| Длительность | 15–30 мин | 24 мин |

**Эмоциональная линия клиента** по эпизодам — значение 0–10 + подпись
(в дизайне цвет кодируется зонами: 0–3 / 4–6 / 7–10 — подписи зон задаёт методист).

**Реплики клиента** (на эпизод): 2 строки × ~40 знаков, как в пузыре **E-22**
(«Я всегда паникую перед экзаменами, руки холодеют»).

**Варианты ответа психолога** (на эпизод): 3–5 штук × ~40 знаков; для каждого —
оценка по 8 навыкам (0–100) и обратная связь в разборе (**E-25**: «сильная сторона»,
«зона роста»).

**Критическая точка** (если есть): реплика-триггер для **E-85** + рекомендации системы
(3 пункта) + что считать корректной реакцией.

## 2. Игра для клиента (E-30…E-44 web, E-50…E-57 TMA)

| Поле | Лимит | Пример |
|---|---|---|
| Название | ~30 зн. | «Дыхание 4-7-8» |
| Тип | словарь | Упражнение / Медитация / Дневник / Техника |
| Тема | словарь | Тревога / Стресс / Эмоции |
| Длительность | 3–12 мин | «5 мин» |
| Описание (E-40) | 3 строки × ~44 зн. | «Простая техника дыхания, которая…» |

**Шаги** — по порядку, тип из 7 (макеты: `screens/06`, секция «E-42 · Типы шагов»):

- **text** — карточка с текстом (до 3 строк);
- **card** — карточка с заголовком + текст + изображение-плейсхолдер;
- **timer** — цикл дыхания: «вдох N сек / задержка N / выдох N» (в дизайне 4-7-8,
  кольцо-анимация); подпись шага до ~30 зн.;
- **scale** — вопрос + шкала 0–10 + подписи трёх зон (низкая/средняя/высокая);
- **choice** — вопрос (до ~34 зн.) + 2–4 варианта × ~24 зн.; для ветвления (branch)
  укажите «если выбран вариант X → перейти к шагу Y»;
- **input** — вопрос + подсказка-плейсхолдер (лимит **300** знаков, счётчик в дизайне);
- **branch** — не отдельный экран: логика ветвления описывается комментарием.

**Завершение (E-43)**: текст «что произошло» (2 строки) + текст автосообщения психологу.

**Ошибка доступа (E-44)** — используется общий макет, тексты менять не нужно.

## 3. Приветствия TMA (E-50/E-51)

- Заголовок онбординга: «Пространство спокойствия» (можно заменить, ~26 зн.);
- 3 преимущества: ~34 знака каждый (иконки sparkles/lock/key-round уже подобраны);
- «Совет дня»: 2 строки × ~40 знаков, запас — пул из 30+ советов для ротации.

## 4. Формат сдачи

Markdown или таблица (Google Sheets) со столбцами: `объект · поле · текст · лимит · статус`.
Разработка заводит тексты в контентную базу; дизайнер при необходимости обновляет макеты
(плагин Platform Builder можно перезапустить — макеты пересобираются идемпотентно).

**Готовые тексты из макетов можно использовать как образец тона**: обращения на «вы»,
без жаргона, поддерживающие формулировки, никакого давления («можно остановиться
в любой момент», «пара слов — этого достаточно»).
