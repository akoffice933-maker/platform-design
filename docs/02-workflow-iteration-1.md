## Шаги в Penpot (после docs/01-setup-penpot.md)

1. **Импорт токенов**: Tools → Tokens → Import → `tokens/design-tokens.json`.
2. **Запуск плагина** Platform Builder (v0.2) (Plugin manager → URL манифеста).
   Результат: цветовые стили `color/*` (33 шт.), текстовые стили `text/*` (10 шт.),
   борд `01_Foundations / audit` на текущей странице.
3. **Проверить стили**: панель Assets → Colors/Typographies — имена сгруппированы
   по `/` (color/bg, color/text, color/skill…).
4. **Библиотека Platform Core**: меню файла → Publish library → подключить к другим
   файлам проекта как shared library.
5. **Иконки**: перетащить `icons/lucide/*.svg` на страницу `01_Foundations`
   (импорт SVG создаёт векторные фигуры), превратить каждую в компонент
   `icon/<имя>` (или массово — выделить все → create component). Размеры 16/20/24/32.
6. **Grid styles**: для фреймов настроить layout grids по ТЗ 2.3:
   - Desktop 1440: 12 col, gutter 24, margin 120
   - Tablet 768: 8 col, gutter 16, margin 32
   - Mobile 390: 4 col, gutter 16, margin 16
   - TMA 390: 4 col + сверху отступ 56px, снизу 80px (зона MainButton)
