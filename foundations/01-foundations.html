Кнопки на этих цветах — только с dark-label либо перекрашивать фон в более тёмные оттенки (открытый вопрос №2 в Handoff).
text/tertiary — только disabled и плейсхолдеры#94A3B8 на белом даёт 2.56:1. Запрещено для читаемого текста, подписей полей и сообщений. Для secondary-текста использовать #475569 (7.58:1).
Эмоции и статусы: никогда не только цветПо ТЗ 8.1 смысл передаётся иконкой + цветом (EmotionIndicator: иконка low/mid/high + цвет). Цвет emotion/mid на белом — 2.15:1, поэтому в текстовых контекстах его дублировать формой/иконкой/подписью.

Правила работы в Penpot ТЗ 2, 9

Только styles: цвета — color styles, шрифты — text styles, тени — shadow styles. Сырой hex/размер в слое — дефект приёмки (11.2).
Компоненты с вариантами: Button/primary/hover, Input/default/focus… Нейминг: ComponentName / Variant / State (9.3).
Фреймы экранов: E-XX Название / breakpoint — например E-22 Session Active / 1440.
Слои: осмысленные имена без «Rectangle 23»; логическая группировка.
Flex Layout вместо привычного auto-layout из Figma; сложная логика прототипа — комментариями (ограничения Penpot, ТЗ 12.4).
Библиотеки: «Platform Core» (токены + UI-kit) и «Platform Illustrations» — shared libraries между страницами проекта (2.2).
Экспорт токенов для разработчиков: Tools → Tokens → Export (DTCG JSON) или готовый tokens/tokens.css + пример Tailwind-конфига внутри него (9.2).
